# chem-report-tool

大学の化学実験レポートで毎週発生する「同じ計算・作図の手作業」を減らす個人開発ツール。

## 背景・課題
実験レポートでは、測定値のCSVから濃度換算・グラフ作成・表の整形を毎回手作業で行っている。
1レポート全体で約10時間かかっており、そのうち計算と作図の作業が約3時間を占める。
毎回同じ処理の繰り返しで、転記ミスも起きやすい。

## できること（現状）
- 測定データ（CSV）の読み込みと整形
- 導電率測定データの計算処理
- 計算結果のグラフ出力（matplotlib）

## 使い方
notebooks/03_conductivity.ipynb を Jupyter で開いて実行する。
出力した表・グラフをレポート（Word）に取り込む。

## 技術構成
Python 3 / pandas / numpy / matplotlib / Jupyter Notebook

## 設計方針：全自動生成をやめた理由
当初（v1）は nbconvert と pandoc を使い、notebook から Word レポートまで
一括生成する構成を作った（build.py に実装が残っている）。
しかし、実際に使うと数式・図表のレイアウト調整に手戻りが多く、
自動化の工数に対して短縮できる時間が小さいと判断した。

そこで v2 では、自動化の範囲を「計算と作図」に絞り、
文書整形は手作業に残す構成へ変更した。
build.py は現在は使用していないが、判断の経緯を残すため保持している。
