# chem-report-tool

大学の化学実験レポート作成を効率化する個人開発ツール。
毎週のレポートで発生していた「同じ計算・作図の手作業」を自動化する。

## 背景・課題
実験レポートでは、測定値のCSVから
検量線の作成・濃度換算・有効数字の処理・グラフ作成を毎回手作業で行っており、
1レポートあたり【10】時間を消費していた。ミスも起きやすい。

## できること（現状）
- 測定データ（CSV）の読み込みと整形
- 【導電率測定データの計算処理】
- 計算結果のグラフ出力（matplotlib）

## 使い方

python build.py

Jupyter Notebook（`notebooks/`）で計算・作図を行い、
出力した表・グラフをレポートに取り込む。

## 技術構成
Python 3 / pandas / numpy / matplotlib / Jupyter Notebook

## 設計方針
当初はWordレポートまでの全自動生成を目指したが、
レイアウト調整の自動化に工数がかかる割に効果が薄いと判断し、方針を変更。
Pythonは「計算と作図」という自動化の効果が大きい部分に限定し、
最終的な文書整形は手作業に残す構成にした。
