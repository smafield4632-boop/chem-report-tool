# chem-report-tool

基礎化学実験のレポートを、CSVから表・グラフ・数式つきWordファイルとして自動生成するツール。 応用化学科の実験レポートで実際に運用中。

## 何をするか

実験で測定した数値をCSVに記録すると、以下がまとめてWordファイルとして出力される。

- 測定値の表（有効数字を保持）
- 濃度依存性のグラフと最小二乗法による外挿
- 単位換算を含む化学計算（比伝導率 → モル伝導率 → 溶解度）
- 下付き文字つきの化学式と、編集可能なWord数式

## 使い方

    python build.py   # → output/report.docx

## 構成

- `data/` … 実験で測定した生データ（CSV）
- `notebooks/` … 計算・作図・本文
- `build.py` … Markdown経由でWordに変換
